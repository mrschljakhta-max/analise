# OSM MAP STUDIO · Публічні населені пункти Cloudflare D1

## Scope

Підключено лише **відкритий довідник населених пунктів** до карти; це не загальний механізм виведення будь-яких довідників. Дані беруться з уже наявної таблиці `directory_entries` для **єдиного** коду `directory_id='settlements'`.

Авторизований адміністратор ANALISE відкриває `/api/gis-preview`, розгортає ліву панель та вмикає `Населені пункти (D1)`. За замовчуванням цей шар вимкнений.

## Безпека і формат

- Новий endpoint `GET /api/gis/settlements?south=...&west=...&north=...&east=...`.
- Cloudflare Access перевіряє токен ще до маршруту, далі обов'язковий активний `admin`.
- Приймає лише коректний bounding box до **14° широти та 24° довготи**. Для огляду більшої області потрібно збільшити карту.
- Повертає максимум **200** записів за запит: `id,name,type,lat,lon`. `more=true` сигналізує, що частина результатів обрізана.
- Пошук лише в публічному цивільному довіднику. Не повертаємо `data_json` цілком, MGRS, персональні дані чи будь-які військові таблиці.
- **Read-only:** тільки SQL `SELECT`. Жодних міграцій і змін до D1/R2.
- Навігація по карті призводить до запиту після затримки 450 мс, попередній запит скасовується, якщо карта змінилася.
- Маркери позначають умовні географічні центри населених пунктів із D1, а не військові позиції.
- За масштабу менше 7 або надто широкого охоплення шар підказує збільшити карту.
- Шар жодним чином не додає до карти оперативні БпЛА, ВП/СП чи дані станцій/їхньої геометрії.

## Обмеження

Точність координат залежить від вмісту довідника. Код не гарантує, що у Cloudflare D1 є населені пункти з валідними `lat/lon`; якщо немає, відобразиться **0**. Не робити твердження про завантаження конкретних поселень без фактичного smoke-тесту.

Точні позиції захищених об'єктів, маршрути БпЛА та сектори роботи військової техніки тут не підключаються. Для спільного інтерфейсу можуть використовуватися лише синтетичні навчальні шари або несекретні агреговані статистичні дані.

## Smoke test

1. Відкрити /api/gis-preview під Cloudflare Access з активним admin.
2. Кнопкою керування шарами відкрити ліву панель і поставити прапорець `Населені пункти (D1)`.
3. Пересунути карту та змінити масштаб: індикатор повинен показати кількість записів, точки перемістяться відповідно до підкладки.
4. Натиснути на точку: показується назва та тип із публічного довідника.
5. Вимкнути шар: маркери зникають. Перевірити, що D1-процес імпорту та інші модулі ANALISE не змінені.
6. `cd api && npm test`, Worker bundle, після мерджу Cloudflare Deploy.
