# OSM MAP STUDIO · навчальні шари БпЛА / ВП/СП / Станції

## Реалізовано

У захищеній сторінці `/api/gis-preview`, поруч із шаром публічних населених пунктів D1, додано три окремі **навчальні** категорії:

1. БпЛА — класифікація «Крило», «Мультироторний», «FPV».
2. ВП/СП — умовні позначення «ВП», «СП».
3. Станції — умовні класи «Виявлення», «Подавлення», «Комбінована».

Кожна категорія має перемикач видимості умовної легенди, селектор класу та посилання на чинну захищену сторінку довідника ANALISE (`/api/uav-catalog`, `/api/vp-directory`, `/api/station-directory`).

Після ввімкнення категорії на картографічному полотні відкривається **окреме плаваюче вікно схематичної легенди**, яке можна приховати. Воно НЕ розміщує географічних позначок і НЕ змінює картографічну підкладку. Сектор станції зображено маленькою довільною схемою в легенді **без масштабу та географічної прив'язки**.

## Обмеження безпеки

- Навчальні шари не надсилають жодних HTTP-запитів до військових довідників.
- Не читають і не відображають реальні позиції ВП/СП, записи БпЛА, місцеположення станцій, маршрути, азимути, дальності, частоти, часові показники чи сектори дії.
- Вони не є GIS-відображенням фактичних даних із D1. Посилання **«Довідник ↗»** відкриває існуючі відокремлені захищені довідники у відповідному інтерфейсі.
- Існуючий шар **публічних населених пунктів D1** залишається єдиним реально геоприв'язаним підключенням до D1 на цій сторінці.
- Робоча база `analise-db`, Cloudflare Access і схеми D1 не змінюються; нових API для військових шарів немає.

## Приймальні перевірки

1. Відкрити `/api/gis-preview` після Cloudflare Access, за потреби `Ctrl+Shift+R`.
2. Розгорнути ліву панель через кнопку шарів. Після «Населені пункти (D1)» побачити три блоки навчальних категорій.
3. Послідовно ввімкнути кожну категорію; перевірити появу навчальної легенди та роботу фільтрів.
4. Переконатися, що жодні географічні точки або справжні сектори не з’являються на самій карті через ввімкнення цих блоків.
5. Перевірити переходи «Довідник ↗» до вже наявних розділів ANALISE.
6. Вимкнути всі перемикачі — вікно легенди має зникнути.
7. `cd api && npm test`, Cloudflare Workers bundle, CI і production Deploy.

## Наступні безпечні етапи

Розвивати **публічні/невійськові** геодані (населені пункти, адміністративні межі, цивільні об'єкти), статистику без точного місцезнаходження та незалежні навчальні набори для GIS-редагування. Реальні геоприв'язані шари військової обстановки тут не реалізуються.
