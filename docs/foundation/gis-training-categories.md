# OSM MAP STUDIO · Три навчальні шари з умовними маркерами

## Реалізовано

У чинній захищеній карті `/api/gis-preview` **усі три навчальні шари увімкнені одночасно**:

- **БпЛА:** Крило, Мультироторний, FPV — 3 умовні маркери.
- **ВП/СП:** ВП, СП — 2 умовні маркери.
- **Станції:** Виявлення, Подавлення, Комбінована — 3 умовні маркери.

Після перевірки користувачем рамкову мінісхему замінено **окремими видимими значками безпосередньо над картографічною підкладкою**. Усі вісім маркерів різних категорій розподілені по картографічному екрану без великої рамки, кожен має позначку **DEMO**. Верхній компактний підпис «УМОВНІ СИМВОЛИ · БЕЗ ГЕОПРИВ’ЯЗКИ» прямо пояснює, що розташування вигадане.

Їхні положення — лише фіксовані відсотки **екрана**, не координати земної поверхні. Навчальні символи **не переміщуються разом з OSM**, тоді як цивільні точки D1 залишаються геоприв'язаними. Порожні місця накладки пропускають натискання, тому перетягування/масштабування карти працює як раніше.

Кожен шар має перемикач, селектор класу, лічильник і посилання на чинний захищений довідник. Вимикання шару забирає його позначки, а фільтр лишає лише обраний клас. Натискання на приклад маркера відкриває навчальну картку й заповнює інспектор без координат чи службових даних. Вимкнення всіх шарів прибирає всі умовні значки та інформаційний підпис.

Картка станції має лише абстрактний символ без кутів, дальностей, напрямків і географічного сектора.

## Чітке розділення джерел

- Населені пункти — **реальні цивільні координати з наявного Cloudflare D1**, функціональний картографічний шар.
- Навчальні БпЛА, ВП/СП, станції — **лише статичні вигадані типи**, без запитів до D1 і без географічної прив'язки. Це інтерактивна навчальна накладка на картографічному екрані, **не геодані**.
- Жодні реальні військові позиції, маршрути, сектори, події, характеристики техніки чи частоти не зчитуються й не розміщуються на карті. Не створено жодної таблиці, міграції або додаткового бекенду.

## Перевірка

1. Відкрити `/api/gis-preview` після Cloudflare Access та жорстко перезавантажити сторінку.
2. Переконатися, що всі три навчальні перемикачі активні, а **на карті, а не в окремій рамці**, є 8 підписаних значків DEMO.
3. Обрати класи в трьох фільтрах: позначки мають відповідно зникати або залишатися.
4. Натиснути на будь-який значок безпосередньо над картою: відкриється картка; натиснути на значок станції — з'явиться абстрактна схема без сектора.
5. Перетягнути/збільшити OSM. Цивільні населені пункти мають залишатися геоприв'язаними, **навчальні символи — нерухомими всередині рамки схеми**.
6. Вимкнути всі три групи — усі навчальні значки й підпис повинні зникнути.
7. Перевірити тести: `cd api && npm test`; GitHub Actions; після мерджу виконати окремий ручний `Deploy ANALISE API` з `main`.

Тестовий DOM-сценарій перевіряє початкові 8 маркерів, перемикання груп, фільтр одного класу, натискання й роботу інспектора. Цивільний SQL-шар і Cloudflare Access не змінено.
