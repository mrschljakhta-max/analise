# ANALISE — головна сторінка та єдина навігація

## Початкова адреса

- `/`, `/api`, `/api/` перенаправляють на `/api/dashboard`.
- `GET /api/dashboard` — захищений HTML Dashboard.
- `GET /api/dashboard.css`, `GET /api/dashboard.js` — статичні ресурси.
- `GET /api/dashboard/data` — підсумкові значення із D1.
- `GET /api/global-nav.css`, `GET /api/global-nav.js` — однакова верхня навігація між каталогами.

Усі сторінки та ресурси проходять існуючу перевірку Cloudflare Access JWT і чинного користувача в D1. Нова міграція D1 не потрібна.

## Функції

1. Головна сторінка із живими загальними кількостями: населені пункти, підрозділи, станції, моделі станцій, моделі БпЛА, назви ВП та СП.
2. Пошук **лише назв розділів**, а не пошук об'єктів за місцеположенням або підпорядкованістю.
3. Посилання на вже наявні довідники, локальні Excel-імпортери, каталог та окремий «Робочий простір».
4. Навігаційна панель на сторінках довідників; робочий простір із власним сайдбаром отримав окреме посилання на Dashboard.
5. Адаптивна сітка для мобільних пристроїв, клавіатурна доступність меню, підтримка `prefers-reduced-motion`.

## Права доступу

API `/api/dashboard/data` повертає **тільки агреговані лічильники** й дату формування. Для користувача з роллю `admin` — сім кількостей; для інших активних користувачів `counts: null`. Адміністративні картки й посилання приховані в HTML до підтвердження ролі; серверні API кожного каталогу перевіряють власні права незалежно від фронтенду.

Ні на Dashboard, ні в цій відповіді API не відображаються координати, картографічні точки, позиції, підроздільні зв'язки конкретних станцій або ВП, оперативна інформація чи технічні профілі. Помилки SQL приховуються, замість вигаданих нулів повертається 503.

## Дані та сумісність

- Джерело чисел — `directory_entries`, `org_units`, `stations`, `station_types`, `uav_models`, `vp_sp_objects`.
- Показники не підставляються з демонстраційних значень чи кешу; кнопка «Оновити показники» запитує D1 знову.
- Для існуючих сторінок додано лише посилання на спільні CSS/JS навігації; їхні маршрути, форми імпорту й логіка збереження не змінюються.
- Захист навігації не замінює серверний контроль доступу.

## Перевірка й розгортання

Запусти GitHub Actions **Deploy ANALISE API** (гілка `main`); workflow перевіряє синтаксис, тести, створює dry-run пакет і викладає Worker. Нову міграцію D1 запускати не треба.

Після Deploy відкрий `https://analise-api.mr-schljakhta.workers.dev/api/dashboard`, звір лічильники з довідниками, перевір пошук, мобільний вигляд, меню «Розділи» та «Excel», а потім переходи з «Робочого простору» назад на головну.
