# ANALISE · Універсальний парсер і локальний попередній перегляд

## Поточний стан
Окремий модуль `api/src/generic-ooxml-parser.js` читає таблиці у звичайних DOCX/XLSX без тестового маніфесту. Враховуються назви аркушів, типи комірок, кешовані значення формул, дати Excel, злиті діапазони Excel й `gridSpan` / `vMerge` Word.

Сторінка `/api/generic-preview` виконує **окремий локальний браузерний перегляд**. Вона працює через `File.arrayBuffer`, `DOMParser` та `DecompressionStream('deflate-raw')` без `fetch` / XHR для файлу, не надсилає документи на Worker, не зберігає файли в D1/R2 або локальному сховищі. Зберігаються тільки тимчасові об'єкти в пам'яті вкладки.

Авторизація сторінки та її ресурсів як і в інших інтерфейсах ANALISE: Cloudflare Access і активна роль `admin`.

## Перевірка
1. Відкрити `/api/generic-preview` після Deploy API.
2. Обрати **цивільний або вигаданий** Word/Excel до 8 МБ.
3. Перевірити перелік аркушів/таблиць, назви, підсумки та перемикання.
4. В Excel порівняти розташування значень, дати та порожні колонки.
5. Перемкнути сторінки таблиці, натиснути «Скинути перегляд».
6. У DevTools → Network перевірити, що при виборі файлу немає POST із вмістом документа.
7. Переконатися, що `/api/synthetic-upload` працює як раніше, D1-записи та правила не змінено.

## Обмеження v1
- Підтримуються DOCX/XLSX, не DOC/XLS, PDF, ZIP пакетів, XLSM чи зашифровані документи.
- Це **структурний перегляд**, не відтворення оригінального дизайну; не декодуються картинки, фігури, стилі та діаграми.
- Формули не виконуються, відображається збережене кешоване значення (якщо воно є).
- Excel: не більше 80 видимих колонок в одній таблиці, 30 рядків на сторінку; merged range відображається у статистиці, але не зливає клітинки графічно.
- Складні вкладені таблиці Word можуть потребувати окремого покращення.
- `DecompressionStream('deflate-raw')` вимагає сучасного браузера (перевіряли орієнтацію на Chromium); якщо браузер не підтримує API, сторінка повідомить про це.
- Програма не робить висновків щодо чутливості даних. Не вводити в систему несанкціоновані чутливі матеріали. Для початкової перевірки застосовувати нейтральні документи.
- **Немає збереження структурованих записів у D1**; інтеграцію із шаблонами/довідниками та транзакційним імпортом реалізуємо окремо після перевірки парсера.

## Архітектурна межа
Універсальний парсер і локальний перегляд не викликають `/api/synthetic-upload/ingest`, `/api/purgatory/ingest` або жодного іншого write API.
Попередній тестовий імпортер, «Чистилище», довідники, історія версій і Cloudflare D1 залишаються без змін. Для цього кроку **не потрібна міграція бази**.

## CI
